# Опросы

Небольшое приложение на FastAPI: создание опросов, голосование и результаты.
Веб-страница работает без внешних API, CDN и сборки интерфейса.

## Запуск

Нужен Python 3.12. Выполняй из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8002
```

Страница: http://127.0.0.1:8002/
Документация API: http://127.0.0.1:8002/docs
Остановка: Ctrl+C.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | `/polls` | Создать опрос |
| GET | `/polls` | Список опросов, новые первыми |
| GET | `/polls/{id}` | Вопрос и варианты ответа |
| POST | `/polls/{id}/votes` | Проголосовать |
| GET | `/polls/{id}/results` | Количество голосов и проценты |

Пример создания:

```json
{"question":"Какой язык изучать?","options":["Python","Go","Rust"]}
```

Пример голосования в первом опросе:

```json
{"option_id":1}
```

Вопрос — от 1 до 200 символов после удаления пробелов по краям.
От 2 до 8 вариантов, каждый от 1 до 100 символов.
Повторяющиеся варианты, в том числе с разным регистром, отклоняются.
Неизвестный опрос возвращает 404, неверные данные — 422.
Проценты округляются до одного знака: сумма может немного отличаться от 100%.

## Устройство и ограничения

`app.py` содержит модели входных данных, хранилище в памяти и маршруты.
`index.html` — страницу и запросы к API. Поле `votes` внутреннее:
ответы создания и просмотра опроса показывают только вопрос и варианты;
результаты доступны отдельным маршрутом.

Данные исчезают после перезапуска. Используется один процесс сервера.
Регистрации и защиты от повторных голосов нет: один человек может голосовать
несколько раз. Результаты обновляются при открытии опроса, голосовании или
нажатии «Обновить результаты».

Это исходная версия приложения. Тесты, CI, служебные маршруты,
настройки окружения и собственное логирование пока не добавлены.
