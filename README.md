# Опросы

Учебный сервис на FastAPI: создание опросов, голосование, просмотр результатов
и закрытие голосования. Подходит для небольших опросов в учебной группе.
Веб-страница работает без внешних API, CDN и сборки интерфейса.

## Возможности

- Создание опроса с вопросом и 2–8 вариантами ответа.
- Список опросов и просмотр выбранного опроса.
- Голосование, число голосов и проценты для каждого варианта.
- Закрытие опроса с запретом дальнейшего голосования.
- Проверка состояния через `/health` и версия через `/version`.
- Настройка версии через переменную окружения и `.env`.
- Логи запуска, остановки, создания и закрытия опросов, принятых голосов.
- Три автоматических теста API.

## Установка

Нужен Python **3.12**. Команды выполняются из корня проекта.
При первой установке создай виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

Проверь `python3 --version` перед созданием окружения. Если на компьютере несколько
версий Python, используй `python3.12 -m venv .venv`.

Если `.venv` уже создано, повторно создавать его не нужно:

```bash
source .venv/bin/activate
```

Убедиться, что активировано окружение именно этого проекта:

```bash
which python
```

Путь должен вести в `.venv/bin/python` внутри папки проекта.
Одна надпись `(.venv)` в терминале не гарантирует правильный путь.

## Настройки

Для локальной настройки скопируй пример, если `.env` ещё нет:

```bash
cp -n .env.example .env
```

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_VERSION` | `0.1.0` | Значение, возвращаемое маршрутом `/version` |

Приложение загружает `.env` рядом с `app_final.py` при запуске.
Переменная процесса имеет приоритет над значением из `.env`.
После изменения `.env` перезапусти сервер.
Настоящий `.env` исключён из Git; в репозитории хранится `.env.example`.

## Запуск

Обычный запуск без автоматического перезапуска:

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8002 --workers 1
```

Запуск для разработки:

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8002 --reload
```

- Приложение: <http://127.0.0.1:8002/>.
- Документация API: <http://127.0.0.1:8002/docs>.
- OpenAPI: <http://127.0.0.1:8002/openapi.json>.

Остановка — `Ctrl+C` в терминале с сервером. Выход из окружения — `deactivate`.
Для другого порта измени `--port` и адреса в запросах.
Используй один worker: каждый процесс имеет собственное хранилище в памяти.

Пример запуска с другой версией:

```bash
APP_VERSION=0.2.0 python -m uvicorn app_final:app --port 8002
```

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Веб-страница |
| POST | `/polls` | Создать опрос; ответ 201 |
| GET | `/polls` | Список опросов, новые первыми |
| GET | `/polls/{id}` | Вопрос, варианты и состояние `closed` |
| POST | `/polls/{id}/votes` | Проголосовать и получить результаты |
| GET | `/polls/{id}/results` | Число голосов и проценты |
| POST | `/polls/{id}/close` | Закрыть опрос |
| GET | `/health` | Состояние процесса: `{"status":"ok"}` |
| GET | `/version` | Версия приложения из настроек |

Вопрос — от 1 до 200 символов после удаления пробелов по краям.
От 2 до 8 вариантов, каждый от 1 до 100 символов.
Повторяющиеся варианты, в том числе с разным регистром, отклоняются.

### Пример работы

В отдельном терминале создай опрос:

```bash
curl -i -X POST http://127.0.0.1:8002/polls \
  -H 'Content-Type: application/json' \
  -d '{"question":"Что изучать?","options":["Python","Go"]}'
```

Из ответа возьми `id` опроса. В примерах ниже используется `1`;
замени его, если сервер вернул другое число.

Проголосовать за первый вариант:

```bash
curl -i -X POST http://127.0.0.1:8002/polls/1/votes \
  -H 'Content-Type: application/json' \
  -d '{"option_id":1}'
```

Посмотреть результаты и закрыть опрос:

```bash
curl http://127.0.0.1:8002/polls/1/results
curl -i -X POST http://127.0.0.1:8002/polls/1/close
```

После закрытия `closed` равен `true`, дальнейшее голосование возвращает **409**,
а результаты остаются доступны. Повторное закрытие возвращает 200.
Неизвестный опрос возвращает **404**, неверные данные или неизвестный вариант —
**422** для открытого опроса.

Проценты округляются до одного знака: сумма может немного отличаться от 100%.
В интерфейсе кнопка закрытия появляется после выбора конкретного опроса.
Результаты обновляются при открытии опроса, голосовании или нажатии
«Обновить результаты».

## Автоматические тесты

Используй то же виртуальное окружение, что и для приложения:

```bash
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

`requirements-dev.txt` подключает `requirements.txt` и устанавливает
`pytest` и `httpx` для тестирования API через `TestClient`.
Отдельный сервер для тестов не нужен.

Сейчас в `test_app.py` есть три проверки:

1. `/health` возвращает 200 и ожидаемое тело ответа.
2. Создаётся опрос с двумя вариантами, после чего его можно получить по ID.
3. Голосование в неизвестном опросе возвращает 404.

Ожидаемый результат для текущего набора — **3 passed**.
Перед каждым тестом очищается хранилище тестового процесса и сбрасывается
генератор ID. Данные запущенного отдельно сервера не затрагиваются.

В текущем наборе зависимостей Starlette может показывать предупреждение
о будущем переходе TestClient с `httpx` на `httpx2`; это не ошибка теста.

## Диагностика и логи

При работающем сервере:

```bash
curl -i http://127.0.0.1:8002/health
curl -i http://127.0.0.1:8002/version
```

Ожидается статус 200. При стандартных настройках `/version` возвращает
`{"version":"0.1.0"}`.

Логи выводятся в stderr в терминале, где запущен сервер:

```text
INFO Service started
INFO Poll created id=1
INFO Vote accepted poll_id=1 option_id=1
INFO Poll closed id=1
INFO Service stopped
```

Фактические строки содержат дату и время, а номера зависят от опроса и варианта.
Uvicorn дополнительно выводит сведения о запросах и HTTP-статусах.

| Симптом | Что проверить |
|---|---|
| `No module named pytest` | Путь `which python`, активацию окружения проекта, установку `requirements-dev.txt` |
| `No module named dotenv` | Установлены ли зависимости из `requirements.txt` в активное окружение |
| `Address already in use` | Остановить свой старый экземпляр или выбрать другой порт |
| `Connection refused` | Запущен ли сервер и совпадает ли порт с адресом запроса |
| Кнопки закрытия не видно | Выбрать опрос в списке; при необходимости обновить страницу |
| 409 при голосовании | Опрос уже закрыт |
| 404 после перезапуска | Хранилище в памяти очистилось — создать опрос заново |
| Ошибка при установке через PyPI | Проверить доступ к PyPI; TLS-сбой сам по себе не означает отсутствия версии пакета |

## Ограничения и дальнейшая работа

Данные исчезают после перезапуска, в том числе при автоматической перезагрузке
кода с `--reload`. Регистрации, проверки владельца опроса и защиты от повторных
голосов нет: любой посетитель может голосовать несколько раз и закрыть опрос.

База данных и Docker не используются. GitHub Actions и создание artifact
в текущей версии ещё не настроены. Следующие этапы — расширение тестов,
автоматические проверки и упаковка приложения в CI.
